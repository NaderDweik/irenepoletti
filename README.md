# Personal Portfolio & Professional Website 🌐

> **Live Website:** [https://irenepoletti.github.io/](https://irenepoletti.github.io/)

This repository contains the source code for my personal portfolio website, hosted via GitHub Pages.

---

### 📌 Highlights
- **Focus:** Product Management, Workflow Automation, RegTech (CorpProof Case Study), and Digital Strategy.
- **Academic Background:** M.Sc. Double Degree Student in International Business & Entrepreneurship (University of Pavia & University of Szeged).
- **Tech Stack:** React + Vite, CSS3 (Minimalist Custom Curation), Responsive Design, GitHub Pages Deployment via GitHub Actions.

---

### 🛠️ Development
```bash
npm install
npm run dev      # local dev server
npm run build    # production build into dist/
```
Site content (bio, experience, projects, etc.) lives in `src/data.js`. Pushing to `main` builds and deploys automatically via `.github/workflows/deploy.yml`.
